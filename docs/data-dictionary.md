# Data Dictionary

## canonical-popes

Person-level canonical pope records.

## pontificates

Pontificate-level records. Use this file when sequence, reign, or chronology matters.

## antipopes

Claimant-level records for antipopes and disputed claimants excluded from the canonical succession.

## Key fields

### pope_id

Stable identifier for a canonical pope person.

### pontificate_id

Stable identifier for a specific pontificate.

### annuario_style_sequence

Canonical pontificate sequence in this dataset.

### pontificate_ordinal_for_person

Used for popes with multiple pontificates.

### date_precision

Explains whether the dates are normalized, mixed, approximate, or not yet normalized.
