# Data Quality Notes

This release prioritizes structural correctness.

## Improvements over the original list

- Added Pope Leo XIV.
- Removed duplicate non-pontificate source artifacts for Marinus II and Agapetus II.
- Separated Benedict X into antipopes.
- Modeled Benedict IX with multiple pontificate records.
- Added JSON, CSV, YAML, and TXT exports.
- Added validation scripts and schemas.
- Added Zenodo and citation metadata.

## Known limitations

Many biographical fields are blank pending source-by-source enrichment.

Early papal chronology is uncertain and should be handled carefully in future date normalization work.
